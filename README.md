# 빙의했더니 영지 멸망 3년 전

현대인이 3년 뒤 멸망할 북부 영지의 젊은 영주에게 빙의해, 주민과 관계를 쌓고 마력 균열에 대비하며 영지의 미래와 자신의 새로운 직업을 만드는 인터랙티브 비주얼 노벨입니다.

## 게임 개요

- 장르: 웹소설풍 빙의·영지 경영 인터랙티브 비주얼 노벨
- 목표 플레이타임: 1회 10~15분
- 핵심 경험: NPC와의 자유 대화, 결정적 선택, 영지 경영, 플레이 기록 기반 직업 엔딩
- 배경: 3년 뒤 북부 하늘에 마력 균열이 열리고 세 개의 봉화가 꺼지면서 영지가 멸망한다.
- 플레이어의 목표: 제한된 자원과 관계를 활용해 균열에 대비하고 주민과 영지의 운명을 바꾼다.

## 전체 게임 흐름

```text
타이틀 및 새 게임
    ↓
Act 1 · 빙의와 멸망 예고
에드윈의 영지 보고 → 자유 대화 → 첫 복구 방침
    ↓
Act 2 · 균열 대응 계획
리아와 봉화 조사 → 군사·봉인·외부 지원 전략 결정
    ↓
Act 3 · 마력보리 농사
마르타와 생활 대화 → 밭 정리·씨앗·물 배분 미니게임
    ↓
Act 4 · 균열 발생
누적된 준비 회수 → 20초 최종 대응 → 영지 운명 판정
    ↓
직업 및 후일담 엔딩
영지 결과 + 직업 위상 + 플레이 성향에 맞는 직업과 에필로그
```

게임의 주요 사건과 상태 변화, 성공·실패, 영지 운명은 서버의 결정론적 규칙으로 판정합니다. AI는 NPC 대사와 엔딩 표현을 보조하지만 게임 상태를 직접 변경하지 않습니다.

## 주요 게임 시스템

- 핵심 상태: `military`, `treasury`, `legitimacy`, `ward`
- NPC 관계: 신뢰, 두려움, 의심, 공개된 사실
- 플레이 성향: 다정함, 냉혹함, 달변, 통찰, 실리, 무모함, 기행, 위협
- 직업 적성: 전투, 마법, 외교, 상업, 지도력, 제작
- 엔딩: 영지 운명과 직업 위상·톤을 독립적으로 판정한 뒤 후일담으로 결합
- 안정성: 실제 AI 모드와 인터넷 없이 완주 가능한 Mock 모드 지원

## 기술 스택

| 영역 | 기술 | 역할 |
| --- | --- | --- |
| 클라이언트 | Godot Engine 4.x, GDScript | 2D 비주얼 노벨 UI, 입력, 선택지, 미니게임 |
| 서버 | C#, ASP.NET Core Web API, .NET 10 | 세션, 진행 검증, 상태 계산, 엔딩 판정 |
| 데이터 | SQLite, Entity Framework Core | 세션 상태, 이벤트 로그, 관계와 적성 저장 |
| 콘텐츠 | JSON | NPC, 장면, 선택지, 상태 변화 규칙 |
| AI | OpenAI Responses API, Structured Outputs | 서버 측 NPC 대사와 직업 후일담 표현 생성, 오류 시 고정 콘텐츠 폴백 |
| 버전 관리 | Git, GitHub | 기능 단위 변경 이력과 문서 관리 |

## 프로젝트 구조

```text
game-project/
├─ client/          # Godot 프로젝트
├─ server/          # ASP.NET Core Web API
├─ content/         # NPC, 사건, 선택지 JSON
├─ docs/            # 제품 명세와 개발 기록 원본
├─ output/pdf/      # 공유용 개발 기록 PDF
└─ README.md
```

## 실행

서버를 먼저 실행합니다.

```bash
dotnet run --project server/Game.Api/Game.Api.csproj
```

그다음 Godot에서 `client/project.godot`을 열어 프로젝트를 실행합니다.

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path client
```

제품 및 기술 상세 명세는 `docs/게임개발명세서.md`에서 확인할 수 있습니다.
